OpenPeeps release · 19 Aug 2026

2026-08-19-973b9d23-RELEASE

Unread and repost counts tell the truth, admin analytics can be exported, and communities pick their own theme fonts. Posts stay readable when authors or parents are gone, and operators get MCP endpoints plus a one-command local stack.

In the product

What members, moderators, and admins see

Feeds, unread, and reposts

  • Posts show a capped list of who reposted them, instead of leaving that trail hidden.
  • Unseen badges follow the wrapper row for a repost, so a share counts as new even when the original was already read.
  • Group unread uses the same SQL as the badge. Deleted authors no longer inflate unseen counts.
  • Deleted authors and parent posts show a tombstone instead of a broken card.

Composer, polls, and media

  • The visibility you picked keeps a primary border. Polls mark the option you just clicked, and option copy is resolved in the form before save.
  • Closing the media gallery no longer jumps you onto the post page. Direct jam replies stay visible in DMs.

Analytics and theme

  • Each analytics graph can export CSV. DAU/MAU and anonymous click tracking are on the admin rollup.
  • PDF exports use the community name. Metric values stay inside the card. DMs and private-group posts are out of top posts.
  • Community theme settings offer selectable OFL fonts. Save buttons and notification settings use the shared control variants.

Jams, groups, and mobile

  • Jam layout is tighter on small screens. Fullscreen hides when the browser API is missing.
  • Group-card hover covers the whole row. SVG avatars fill the circular crop. Following/followers pages drop the duplicate heading.
  • The React Native app caches hashed media images and cleans up the footer.

In the platform

APIs, runtime, plugins, and operations

MCP and session

  • Community and ops MCP endpoints are in the tree for agent tooling against a live instance.
  • The profiles API fans session events; SSE fan-out and presence have tests.

Moderation, roles, and config

  • Reports stay usable when the reporter is deleted or the viewer is an owner.
  • Saving a role returns the updated record so the capability UI can show success. Empty community profile field keys are rejected.

Inbox speed and restore

  • Unseen inbox counts and conversation APIs are cheaper on the hot path.
  • Restored backups rewrite media URLs to the full server origin, not a relative host that breaks after cutover.

Local and CI

  • One-command local stack includes Mailpit for mail capture.
  • The API performance fixture runs daily, with Redis and JWT_SECRET so the fixture process can start and stay up across workflow steps.

Also in this tag

  • Multi-version component gallery site, with the React UI framework straightened against Figma tokens.
  • Roadmap timeline snapshot refreshed. actions/checkout pinned to the v6.1.0 SHA.
