OpenPeeps release · 26 Aug 2026

2026-08-26-c2a8bbdb-RELEASE

Recurring events share one jam room, groups get a real owner role, and plugins can be installed from admin with live reload. Guests on public jams are quieter and can still see chat profiles. Operators restore a backup into a schema version, then migrate forward.

In the product

What members, moderators, and admins see

Events and jams

  • Recurring events follow a CalDAV-shaped model. The upcoming list shows one row per series, not one per occurrence.
  • Every occurrence of a recurring jam joins the same LiveKit room (the event id), so Live Jams does not list the same call twice.
  • A jam can stream audio and video out over RTMP (for example to StreamYard).
  • Guests no longer refresh in a noisy loop, can read profiles in public jam chat, and do not rejoin after they leave on purpose.

Groups, posts, and polls

  • Groups have an owner role and template-based capability presets. Create/edit forms surface validation errors.
  • Switching a post to an article keeps group visibility. Actions the viewer cannot use are greyed out. Reaction popups link profiles.
  • Poll options enforce a length limit with feedback in the UI.

Auth, language, and mobile

  • Auth layout pages show whether you are already signed in. SSO login URLs are handled as a first-class flow.
  • Language follows profile settings. New-profile notices use the actual profile name.
  • Mobile nav shows the notification unread badge. Wrapping button labels stay centered. Dialogs share one cancel/action footer.

Plugins and analytics

  • Admins can install plugins, with a theme contract and live reload. The page reloads after a plugin reload so the new UI is actually there.
  • Analytics charts follow theme colors, exclude guests from recent signups, and reflow on small screens.
  • Profile custom fields that look like URLs render as links. Open Graph uses the light logo.

In the platform

APIs, runtime, plugins, and operations

Backups and migrate

  • Restore lands on the dump’s schema version, then migrates forward. Backup metadata records createdAt.
  • Post and group media hosts are rewritten on restore so files resolve on the new origin.
  • Migration tests assert journal integrity.

Feed and impressions

  • My feed is filtered before hydration. Latest post view exposes lastAccessed. Repeat post_seen impression rows are allowed.

Packaging and CLI

  • Breaking: React Native components publish as @openpeepshq/rn-components. Host app versions are pinned to match.
  • openpeeps config accepts a namespace option.

Cutover tooling

  • ArangoDB cutover scripts and docs live under archive/ for remaining Postgres migrations, not as runtime.
