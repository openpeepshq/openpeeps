# Community theme fonts

These webfonts are bundled with OpenPeeps so community themes do not load
typefaces from a third-party CDN.

Every family is licensed under the **SIL Open Font License 1.1**. OFL 1.1 is
[GPL-compatible](https://www.gnu.org/licenses/license-list.html#SILOFL): the
fonts may be redistributed with this GPLv3 program. They are **not** relicensed
as GPLv3 — OFL condition 5 requires the Font Software to remain under the OFL.
Each directory contains the upstream `OFL.txt` (copyright notice + license).
